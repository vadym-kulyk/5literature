# Література · 5 клас — уроки-квести Midgard

Сайт: `https://vadym-kulyk.github.io/5literature/`

| Урок | Тека |
|---|---|
| «Золоте яблуко» (кримськотатарська казка) | [`zolote-yabluko/`](zolote-yabluko/) |

## 1. Увімкнути сайт (GitHub Pages, 1 хв)
GitHub → репозиторій `5literature` → **Settings → Pages** → Source: *Deploy from a branch* → гілка `main`, тека `/ (root)` → **Save**.
За хвилину сайт буде на `https://vadym-kulyk.github.io/5literature/`.

## 2. Результати в Google Таблицю (один раз, ~5 хв)
Результати пишуться в таблицю **«Українська 5 — результати»**, в окремий аркуш **«Література 5»**. Аркуші з Firebase (Спроби, Учні, Прогрес…) не змінюються.

1. Відкрий таблицю «Українська 5 — результати» → **Розширення → Apps Script**.
2. Ліворуч біля «Файли» натисни **＋ → Скрипт**, назви його `Literatura` і встав увесь код із [`apps-script/Literatura.gs`](apps-script/Literatura.gs). `Code.gs` не чіпай. Збережи 💾.
3. Угорі обери функцію `litSetup` і натисни **▶ Виконати**. З'являться аркуші «Література 5» і «Література — відповіді».
4. **Розгорнути → Нове розгортання** → ⚙️ **Веб-застосунок**: виконувати як **Я**, доступ **Усі**. Натисни **Розгорнути** і скопіюй адресу, що закінчується на `/exec`.
5. Встав адресу у файл [`config.js`](config.js) між лапками (на GitHub: олівець ✏️ → Commit changes).

### Що потрапляє в таблицю
- **Література 5**: один рядок на учня й урок (клас + ім'я) — пара, бали %, скільки станцій виконано, бали за кожною станцією, скарби, загадки, таємна кімната. Рядок оновлюється, а не дублюється.
- **Література — відповіді**: письмові відповіді (напр., «Рада мудреців»: рішення й пояснення).

Сайт надсилає дані сам через кілька секунд після кожного виконаного завдання, коли учень закриває вкладку, і за кнопкою «📤 Надіслати вчителю» у Скарбниці. Без класу й імені нічого не надсилається.
