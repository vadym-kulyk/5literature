## 1. Увімкнути сайт (GitHub Pages, 1 хв)
GitHub → репозиторій `5literature` → **Settings → Pages** → Source: *Deploy from a branch* → гілка `main`, тека `/ (root)` → **Save**.
За хвилину сайт буде на `https://vadym-kulyk.github.io/5literature/`.

## 2. Результати в Google Таблицю «5 lit» (один раз, ~5 хв)
1. Відкрий таблицю **«5 lit»** на Google Диску → **Розширення → Apps Script**.
2. Видали все в `Code.gs` і встав код із [`apps-script/Literatura.gs`](apps-script/Literatura.gs). Збережи 💾.
3. Угорі обери функцію `litSetup` і натисни **▶ Виконати**. Google попросить дозволи — підтверди (це твій власний скрипт). З'являться аркуші «Результати» і «Відповіді».
4. **Розгорнути → Нове розгортання** → ⚙️ **Веб-застосунок**: виконувати як **Я**, доступ **Усі**. Натисни **Розгорнути** і скопіюй адресу, що закінчується на `/exec`.
5. Встав адресу у файл [`config.js`](config.js) між лапками (на GitHub: олівець ✏️ → Commit changes).

### Що потрапляє в таблицю
- **Результати**: один рядок на учня й урок (клас + ім'я) — пара, бали %, скільки станцій виконано, бали за кожною станцією, скарби, загадки, таємна кімната. Рядок оновлюється, а не дублюється.
- **Відповіді**: письмові відповіді (напр., «Рада мудреців»: рішення й пояснення).

Сайт надсилає дані сам через кілька секунд після кожного виконаного завдання, коли учень закриває вкладку, і за кнопкою «📤 Надіслати вчителю» у Скарбниці. Без класу й імені нічого не надсилається.

## Моніторинг
- Кожна відповідь зберігається одразу. Оновлення сторінки повертає учня на наступне питання з повідомленням «Сесію відновлено».
- Змінити відповідь не можна. Повторна спроба пишеться окремим рядком «спроба 2 (не впливає на оцінку)».
- Якщо учень почне заново, очистивши браузер чи з іншого пристрою, скрипт запише це окремим рядком з позначкою «⚠ ПОВТОРНИЙ ПОЧАТОК» і не перезапише першу спробу. **Для цього онови код скрипта** (див. нижче).

### Оновити скрипт таблиці «5 lit»
1. Таблиця «5 lit» → **Розширення → Apps Script** → у `Code.gs` заміни весь код на новий із [`apps-script/Literatura.gs`](apps-script/Literatura.gs) → 💾.
2. **Розгорнути → Керувати розгортаннями** → ✏️ біля розгортання → Версія: **Нова версія** → **Розгорнути**. Адреса `/exec` не зміниться.
